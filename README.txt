A LITTLE WORLD FOR YOU
1. Extract this ZIP and open index.html in a browser.
2. Edit recipient and sender in content.js to change names.
3. Copy your recordings into voices/ using the names in voices/README.txt.
4. Upload index.html, content.js and voices/ together to a static web host.
The 270-day schedule starts on first visit on each browser. Daily unlock uses Sri Lanka midnight. Data is stored locally in that browser; clearing site data resets progress. No account, tracking, server or private authentication. Public hosting exposes files, including future gifts and audio; the gift lock is a visual feature, not security. Do not upload private recordings or personal photos to public hosting.
The letters and gifts are starter content, using some combinations of reusable messages. There are no actual audio recordings included. Mini games use randomized matching cards. The first day is an optional welcome voice gift.
